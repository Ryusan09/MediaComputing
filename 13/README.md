## 候補論文（研究関連枠・2026-07-15調査）

修士研究（縄文土器PLYメッシュの縄目圧痕周期・同巡点推定）に関連する2025年以降の英語論文:

1. **SHREC'25 Track on Multiple Relief Patterns: Report and Analysis** (Paolini, Tortorici, Berretti ほか, arXiv:2508.09909, 2025-08) — 三角メッシュ表面のレリーフパターン（規則/準規則）の認識・セグメンテーションのベンチマーク報告。縄目圧痕＝メッシュ上のレリーフパターンそのもので方法論が最も近い。PDF無料: https://arxiv.org/abs/2508.09909
2. **Nets hidden in pottery: Resurrected fishing nets in the Jomon period, Japan** (Obata ほか, Journal of Archaeological Science, 2025) — 縄文土器の網圧痕をX線CTで復元。題材（縄文土器の圧痕）が最も近い。https://www.sciencedirect.com/science/article/pii/S0305440325000809 （要アクセス確認）
3. **Deep learning-based morphological classification of ceramics: 3D point cloud analysis for Sue ware, Japan** (Journal of Archaeological Science, 2026) — 須恵器917点の3D点群をPointTransformerで形態分類。https://www.sciencedirect.com/science/article/pii/S0305440326000026
4. **A Deep Learning Approach to Assist in Pottery Reconstruction from Its Sherds** (Heritage 8(5):167, 2025, MDPI, オープンアクセス) — 破片からの土器復元をCNNで支援。https://doi.org/10.3390/heritage8050167
